# Habit Recovery

A simple, supportive Android app for building healthy habits and restarting after missed days, without guilt or streak pressure. Local-first, works offline, no account.

## Run

```
flutter pub get
flutter run
```

## Test

```
flutter analyze
flutter test
```

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the project structure.

## Get the test app (no tools needed)

Every push to `main` is built by GitHub (analyze, tests, APK, AAB). Download the latest test APK on an Android phone:
https://github.com/sundaysudoku/habit-recovery/releases/download/preview/habit-recovery-test.apk

It is a debug build with Google test ads. See `docs/RELEASE.md` for signing and releasing.
